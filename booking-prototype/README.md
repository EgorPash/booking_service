# booking-prototype

Учебный кликабельный прототип сервиса онлайн-записи для небольшой студии.

## Стек

- HTML5
- CSS3
- vanilla JavaScript
- без backend, без базы данных, без внешних библиотек

## Структура

```
booking-prototype/
├── index.html   — разметка трёх экранов
├── style.css    — стилизация интерфейса
├── script.js    — переключение экранов и логика формы
└── README.md    — описание проекта
```

## Экраны

1. **Лендинг** (`#screen-landing`) — header с названием студии Lumi Beauty Studio, hero-блок с заголовком «Время для себя начинается здесь», CTA «Записаться» и карточки услуг.
2. **Форма записи** (`#screen-booking`) — услуга «Женская стрижка» и интерактивный выбор мастера, даты и времени.
3. **Подтверждение** (`#screen-confirmation`) — заголовок «Запись подтверждена», иконка успеха и карточка с динамическими данными: услуга, мастер, дата и время, выбранные на предыдущем экране.

Все экраны находятся в одном HTML-файле и переключаются без перезагрузки страницы:
JS добавляет/снимает класс `active` у блока `.screen`.

## Как запустить

Открыть `index.html` в браузере двойным кликом либо через локальный сервер:

```bash
npx serve .
# или
python -m http.server 8000
```

## Функциональность

- Кликабельная навигация в шапке и кнопках CTA.
- Услуга «Женская стрижка» зафиксирована как выбранная.
- Интерактивный выбор мастера (Анна, Мария, Елена), даты (21–24 октября) и времени (10:00–18:00).
- Выбранный элемент подсвечивается акцентом и отметкой-галочкой.
- Кнопка «Подтвердить запись» активна только после выбора мастера, даты и времени.
- Выбранные данные сохраняются в объекте `bookingState` и выводятся на экране подтверждения.
- Кнопка «Записаться ещё» сбрасывает выбор.
- Адаптивная вёрстка для мобильных экранов.

## Дизайн-система

Единая система токенов в `style.css` (блок `:root`) — одинаковая на всех экранах:

| Токен | Значение |
|---|---|
| `--bg` | `#F8F7F4` — основной фон |
| `--accent` | `#7C5CFC` — акцентный цвет (CTA, ссылки, иконки) |
| `--text` | `#25232A` — основной текст |
| `--text-secondary` | `#6F6B76` — вторичный текст |
| `--surface` | `#FFFFFF` — карточки и формы |
| `--radius-card` | `20px` — скругление карточек |
| `--radius-btn` | `12px` — скругление кнопок и полей |
| `--font` | `Inter` + системный sans-serif fallback |
| `--shadow-sm / --shadow-md` | мягкие тени |

Все основные CTA используют один класс `.btn.btn-primary` — единый вид на всех трёх экранах.

## Не входит в прототип

Личный кабинет, админ-панель, регистрация, оплата, история записей, отправка SMS/email.
